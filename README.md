# ATM Machine Simulation

## Description
This project is a Python-based ATM Machine Simulation that allows users to perform basic banking operations through a simple command-line interface.

The program demonstrates the use of Python concepts such as functions, loops, conditional statements, dictionaries, and user input.

## Features
- User authentication using a PIN
- Check account balance
- Deposit money
- Withdraw money
- Change PIN (optional)
- Exit the ATM safely
- Displays appropriate error messages for invalid operations

## Technologies Used
- Python 3

## How to Run
1. Download or clone this repository.
2. Open the project in your preferred Python IDE or text editor.
3. Run the Python file:
   ```bash
   python atm.py
   ```

## Example
```
===== ATM MACHINE =====

1. Check Balance
2. Deposit
3. Withdraw
4. Change PIN
5. Exit

Enter your choice:
```
